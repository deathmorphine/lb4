# Лабораторна робота №4 — Weekly Plan

Готова вебсторінка тижневого планера за зразком з лабораторної роботи.

## Реалізовано
1. **CSS Grid:** основна сітка планера з окремою колонкою TO DO, днями Monday–Sunday і блоком вихідних.
2. **Кастомні шрифти:** Oswald та Barlow Condensed (Google Fonts, із запасними системними шрифтами).
3. **Всі чекбокси клікабельні:** відмітки завдань, днів і підсумків тижня.
4. **Всі поля редагуються:** WEEK OF, HEALTHY HABIT, усі 18 завдань та великі текстові поля днів тижня.
5. **Реакція на розмір екрана:** планер займає доступну ширину, а на вузьких екранах прокручується горизонтально, не руйнуючи настільну сітку.

## Додатково
- Збереження заповненого плану в localStorage браузера.
- Кнопка друку з окремими стилями для аркуша.
- Очищення планера з підтвердженням.
- Мітки для доступності клавіатурою та екранних читачів.

## Запуск
Відкрийте файл `index.html` у браузері. Нічого встановлювати не потрібно.

## GitHub Pages
У репозиторії відкрийте **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
